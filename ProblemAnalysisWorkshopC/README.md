## Goal
Augment our term-project dataset with public data, transform it, and explain/predict Ontario listing prices with two simple
linear regressions and one multiple linear regression (variable selection by backward elimination).

## Data
| Source | File |
|:--|:--|
| [Ontario Residential Property Data – Kaggle](https://www.kaggle.com/datasets/mnabaee/ontarioproperties) | `data/properties.csv` |
| [Statistics Canada – Census Profile 2021, census subdivisions](https://www12.statcan.gc.ca/wds-sdw/2021profile-profil2021-eng.cfm) (SDMX API) | `data/census_2021_csd_ontario.csv` |
| [Wikidata](https://query.wikidata.org/) – inception date (P571) of each municipality | `data/municipality_inception_dates.csv` |

`scripts/fetch_external_data.py` shows how the two external files were downloaded.

## How to run (Windows, VS Code)
```powershell
cd ProblemAnalysisWorkshopC
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```
Open `Workshop_C_Linear_Regression.ipynb` in VS Code with `ProblemAnalysisWorkshopC` as the notebook’s working directory. Select the `.venv` kernel, restart it, and choose **Run All**. The cell after Section G prints `model_df ready`. Section O displays the four-model comparison, followed by the regional price table in Section P.
